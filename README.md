# PARKER – Personal AI Assistant

PARKER is a local-first, voice-powered personal AI assistant inspired by futuristic AI systems.

## Vision

Build an intelligent, modular assistant capable of natural voice conversations, persistent memory, approved desktop automation, and cross-device interaction.

## Planned Features

- Local AI powered by Ollama
- Speech recognition and voice synthesis
- Custom assistant personality
- Persistent conversation memory
- Windows desktop interface
- Android companion
- Productivity integrations
- Permission-controlled computer automation

## Technology Stack

- Python
- Ollama
- Qwen
- Faster-Whisper
- Piper TTS
- FastAPI
- SQLite
- PySide6
